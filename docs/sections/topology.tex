\section{Topology-Aware Implementation}

Transitioning the conceptual parallel design to physical hardware requires a specialized network mapping and strict algorithmic guarantees. This section details the adoption of the King's Graph topology to facilitate exchanges between all adjacent nodes. To mathematically validate that this localized communication is sufficient, we introduce $\texttt{Maze}_{16}$, a custom tileset designed specifically to bound the WFC propagation radius, ensuring that no cascading updates ever breach the isolated subdomains.

\subsection{Topologies Considered}
The communication pattern of the algorithm, described in the previous section,
requires each node to exchange data with all its immediate geometric neighbors,
including those in diagonal directions. A standard 2D mesh with 4 neighbors is
therefore insufficient: diagonal communications would require multi-hop routing
through intermediate nodes, introducing additional latency and unnecessary
synchronizations not required by the algorithm.

The adopted topology is the King's Graph, a two-dimensional grid in
which each node is connected to its 8 immediate geometric neighbors both
orthogonal and diagonal. This choice allows the algorithm's communication pattern
to be mapped directly onto the physical topology, guaranteeing that every data
exchange occurs in a single hop, without intermediaries.

\subsection{Embedding the Communication Pattern}
The embedding assigns each node with logical coordinates $(i, j)$ in the node
grid to its corresponding process, preserving two-dimensional spatial contiguity.
Each process communicates directly with its 8 neighbors in the logical grid,
which correspond directly to the physical neighbors in the King's Graph topology,
without any routing indirection.

The correctness of this embedding, however, rests on a non-trivial assumption:
that the propagation originated by any collapse is strictly confined within the
chunks covered by the current mask, never spilling into the domain of a
non-adjacent node. If this condition were violated, the local communication
pattern described above would be insufficient, and global synchronization would
be required at every step. We now establish that this condition is guaranteed
by construction through the design of the tile set.

\subsection{$\texttt{Maze}_{16}$}
In the implementation, cells are updated via a stack that visits propagations
in the following order: Up, Right, Left, Down. The algorithm begins by
recursively updating cells starting from the one immediately above the collapsed
cell, following the order specified above, until an update returns a cell as a
superposition of all possible states at which point the cell is defined as
\textit{virgin} and no further propagation occurs.

To bound this propagation, we designed a specific tile set, hereafter referred
to as $\texttt{Maze}_{16}$:

$\texttt{Maze}_{16}$ consists of 16 tiles, each identified by an index
$i \in \{0, \ldots, 15\}$ and defined on a $3 \times 3$ grid of bits with
fixed corners set to 0. The 16 tiles represent all possible local corridor
configurations, and any valid tiling of an $N \times N$ grid produces a
well-formed classical maze.

We define $\Delta_{prop}$ as the maximum propagation distance of an update for
a given tile set. We claim:

\subsubsection{$\texttt{Maze}_{16}$ Theorem on $\Delta_{prop}$}

\paragraph{Theorem:}
Given the $\texttt{Maze}_{16}$ tileset, it holds that:
\[
    \Delta_{prop}(\texttt{Maze}_{16}) = 1
\]

\paragraph{Proof:}
Since the corners of each tile are always 0, the central pixel of each border
is the only free bit, yielding exactly two possible border patterns:
\begin{itemize}
    \item \textbf{Pattern (a):} border $010$, i.e. the central pixel is 1.
    \item \textbf{Pattern (b):} border $000$, i.e. the central pixel is 0.
\end{itemize}

We denote by $Dir(p, x)$ the update operation applied to a cell of state $x$
in direction $Dir \in \{Up, Right, Left, Down\}$, where $p \in \{a, b\}$
indicates the border pattern exhibited by the source cell toward $x$. The state
$x$ is represented as a subset of $\{s_0, \ldots, s_{15}\}$, and $x = v$
(virgin) denotes the full superposition of all 16 states.

\textbf{Base case single collapsed neighbor.}
We begin by studying propagation in the first direction visited by the algorithm:
Up. Starting from a virgin cell $v$, the two possible updates yield:
\begin{align*}
    Up(a, v) &= \{3, 6, 7, 10, 11, 12, 13, 15\} \\
    Up(b, v) &= \{0, 1, 2, 4, 5, 8, 9, 14\}
\end{align*}

We now move to the updated cell and attempt to propagate recursively. The key
observation is that both resulting sets contain tiles exhibiting both border
patterns toward every direction except the one of provenance (Down). For
instance, toward Up:
\begin{align*}
    Up(a, v) &\ni 3\ \text{(pattern a)},\ 10\ \text{(pattern b)} \\
    Up(b, v) &\ni 1\ \text{(pattern a)},\ 0\ \text{(pattern b)}
\end{align*}
and analogously toward Right and Left. Therefore:
\[
    Up([a,b],\ v) = Up(a, v) \cup Up(b, v) = \texttt{Maze}_{16} = v
\]
All cells adjacent to the first updated cell are necessarily returned to the
virgin state and halt the propagation. By the rotational closure of
$\texttt{Maze}_{16}$ which consists of 6 base tiles $\{0, 1, 5, 9, 13, 15\}$
and their rotations the same argument holds for every initial propagation
direction.

\textbf{Extended cases multiple collapsed neighbors.}
In practice, successive collapses may cause a cell to be updated while more
than one of its neighbors is already collapsed. We distinguish three
exhaustive configurations:

\textit{Case 1: two collapsed neighbors sharing a vertex.}
Consider, for example, the Up and Right neighbors both collapsed. Depending
on their border patterns, the possible resulting states of $x$ are:
\begin{align*}
    Up(a,v) \cap Right(a,v) &= \{5, 9, 10, 15\} \\
    Up(b,v) \cap Right(b,v) &= \{0, 3, 4, 7\}  \\
    Up(a,v) \cap Right(b,v) &= \{1, 8, 12, 13\}
\end{align*}
In each case, the resulting set contains tiles exhibiting both pattern (a) and
pattern (b) toward every free direction. For instance, for $\{5, 9, 10, 15\}$,
denoting by $Dir_p$ the border pattern $p \in \{a, b\}$ exhibited by a tile
toward direction $Dir \in \{L, R, U, D\}$:
\[
    5\ (L_b, D_b),\quad 9\ (L_a, D_b),\quad 10\ (L_b, D_a),\quad 15\ (L_a, D_a)
\]
All combinations of patterns toward Left and Down are represented, so both
adjacent cells are returned to the virgin state. The same holds for the
remaining two sub-cases.

\textit{Case 2: two collapsed neighbors not sharing a vertex.}
When the two collapsed neighbors are opposite (e.g. Up and Down, or Left and
Right), an analogous intersection argument yields sets that still cover both
patterns toward the two remaining free directions, leaving those cells virgin.

\textit{Case 3: three collapsed neighbors.}
This case extends Case 1: starting from a set of 4 tiles such as
$\{5, 9, 10, 15\}$, a third collapsed neighbor (e.g. Down with pattern b)
further restricts $x$ to $\{5, 9\}$. This pair still exhibits both patterns
toward the single remaining free direction (Left):
\[
    5\ (L_b),\quad 9\ (L_a)
\]
and therefore leaves that cell virgin. The argument generalizes to all
combinations of three collapsed neighbors by rotational symmetry.


\textbf{Observation.}
The three cases above, together with the base case, are exhaustive with respect
to propagation. The number of compatible states for a cell with $k$
already-collapsed neighbors follows directly from the case analysis:
\[
    |\text{compatible states}| = 2^{4 - k}
\]
where $k \in \{0, 1, 2, 3, 4\}$. In all cases, as shown above, the updated
cell either returns to the virgin state or is immediately collapsed, and in
neither case does it propagate the update further. The entropy of adjacent
cells is therefore irrelevant to the propagation bound.

Therefore, in all possible configurations, after a single update in any
direction, all cells adjacent to the updated cell are necessarily virgin and
do not propagate the update further, which gives
$\Delta_{prop}(\texttt{Maze}_{16}) = 1$. QED


\paragraph{Corollary 1:}
This result directly validates the embedding described above: since the mask
spans $L > 1$ chunks and $\Delta_{prop} = 1$, no update originating inside
the mask can ever reach the boundary of an adjacent node, making the local
point-to-point communication pattern both necessary and sufficient.

\paragraph{Corollary 2:}
We define a \textit{contradiction} as a configuration in which one or more
cells have entropy zero, that is, their set of compatible states is empty.
From the observation above, the number of compatible states for any cell is
given by $2^{4-k}$, where $k \in \{0, 1, 2, 3, 4\}$ is the number of
already-collapsed neighbors. Since $2^{4-k} \geq 2^0 = 1$ for all admissible
values of $k$, the entropy of any cell is strictly bounded below by 1.
Therefore, no cell can ever reach entropy zero, and no contradiction can arise
during the execution of the algorithm on $\texttt{Maze}_{16}$, therefore $\texttt{Maze}_{16}$ is contradiction free.
