\section{Conclusions}

Developing this project and authoring the accompanying software has been a highly rewarding endeavor, demanding extensive research and dedication. We are deeply satisfied with the final outcomes. Our sole regret stems from the necessity to omit a few sections originally prepared during the development phase, specifically:

\begin{itemize}
    \item \textbf{Further properties of $Maze_{16}$}
    \item \textbf{Extended analysis on Tile Theory}
    \item \textbf{Insights into the parallel development of the post-pipelining phase} mentioned in the discussion.
    \item \textbf{Further performance analysis} regarding the bottlenecks imposed by CAPRI and job scheduling.
\end{itemize}

In particular, the parallel properties were excluded as they would have significantly burdened the narrative without introducing substantial actionable insights.

Regarding the software performance, we are exceptionally pleased to have successfully achieved meaningful parallelization on an algorithm that is notoriously difficult to manage concurrently. The performance gains are highly encouraging, notably yielding a superlinear speedup on a single machine. While the extra-socket synchronization overhead was expected, it becomes negligible relative to the generation time as the chunk size increases.

In conclusion, this project delivers a highly modular framework that generates coherent procedural outputs when paired with any user-defined tileset that respects the necessary propagation constraints.
