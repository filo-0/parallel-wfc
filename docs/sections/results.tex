\subsection{Execution Time}
Comparing the execution time of the serial version of the program with respect to the MPI implementation with 1 single process (as reported in \autoref{fig:SerialeVSP1}), shows us that there are some relevant differences in the two methodologies. \subsection{Speedup}
Because of the differences observed in the previous paragraph, we analyze the speedup of the program as the \textbf{Relative Speedup} of the MPI program with P processes with respect to the execution of itself with one single process:

$$
\text{Speedup relativo: } S(p)=\frac{{T}_{parallel}(1)}{{T}_{parallel}(p)}
$$

Here the average speedup along the different problem size L is reported in figure \autoref{fig:Speedup} for each configuration of P processes:

\subsection{Strong Scaling Efficiency}
With the analysis of the Strong Scaling statistic, we analyze the benefit of using more processors with problems of the same complexity: we are analyzing how efficiently we are making use of the processes.

$$
E(p)=\frac{S(p)}{p}=\frac{{T}_{parallel}(1)}{p*{T}_{parallel}(p)}
$$

The mean of such statistic for each configuration of P i reported in \autoref{fig:StrongScaling}.
